# Project Assets

This directory contains the assets and source files for the Vision Amanya Real Estate Website.

## Structure

*   **`source/`**: Contains original, authoritative project documents (e.g., PDFs, presentations) provided by the client or project team. Original source files in this folder must **never** be modified, compressed, renamed, or altered.
*   **`extracted/`**: Contains assets programmatically or manually generated/extracted from the source documents.
    *   **`images/`**: Contains project photographs, renderings, and other visual assets.
    *   **`floor-plans/`**: Contains floor plans and architectural drawings.
    *   **`documents/`**: Contains extracted supporting documents or text files.
